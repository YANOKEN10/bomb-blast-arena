# VORAZ ROBOT BATTLE

サッカーボールを置いて壁を壊し、爆風で相手を吹き飛ばす、最大4人の対戦アクションです。
ブラウザで開くだけで遊べます。インストール不要・アカウント不要。

**遊ぶ → https://bomb-blast-arena.vercel.app/**

（予備URL: https://yanoken10.github.io/bomb-blast-arena/ ）

## あそびかた

- サッカーボールを置いて逃げ、爆風で相手を倒す。最後の1人になったラウンドの勝ち。3ラウンド先取で優勝。
- ボールは置いてから約1.9秒で爆発します。置いて0.35秒たつとボールが**黄色く光り**、その状態なら「ばくはつ」ボタン（キーボードは Z / R）で**自分の好きなタイミングで爆発させられます**。爆発を待たずに、どんどん壁を壊して進めます。
- ソフトブロック（茶色の箱）を壊すとアイテムが出ます。
- 残り30秒で**サドンデス**。外周から順にブロックが降ってきて、盤面がどんどん狭くなります。
- BGMはステージごとに変わります（曲・テンポ・音色すべて別）。サドンデスに入るとテンポが上がります。

### ストーリー

タイトルの「STORY」から、CPUに勝ち進んでいく全11章のモードで遊べます。

- 章をクリアすると、次の章と**あたらしいステージ**（フリー対戦でも選べるようになります）が開放されます
- 節目の章をクリアすると、**とくべつなキャラの色（★つき・全6色）**が手に入ります
- 先に進むほどCPUの数が増え、反応も速くなります
- 進みぐあいは端末に保存され、ログインしていれば別の端末にも引き継がれます

### アイテム

| アイテム | 効果 |
| --- | --- |
| FIRE | 爆風が1マス長くなる |
| BALL | 同時に置けるボールが増える |
| SPEED | 移動が速くなる |
| KICK | ボールを蹴って転がせる |
| PIERCE | 爆風がブロックを貫通する |
| REMOTE | 時間で爆発しなくなり、完全に自分のタイミングで起爆できる |
| ロングシュート | 爆風が一気に最大まで伸びる |
| ファイアトラップ | わざボタンで設置。前方に炎の壁が約5秒燃え続ける |
| ブタ | 乗ると壁を1マス跳び越えられる。1回やられるとブタだけ死んで自分は助かる |

### 操作

**スマホ・タブレット**：画面下の十字キーとボタン。十字キーは指を滑らせたまま方向を変えられます。

**キーボード**

| キー | 動作 |
| --- | --- |
| ← ↑ → ↓ | 1P 移動 |
| Space | 1P ボールを置く |
| Z | 1P ばくはつ（おいたボールを自分で起爆） |
| Enter | 1P わざ（アイテムの設置・発動） |
| Shift | 1P アイテムをえらぶ |
| W A S D | 2P 移動 |
| F / G / R / T | 2P ボール / わざ / ばくはつ / アイテム |
| P / Esc | ポーズ・再開 |

画面上部の「STOP」ボタンで、対戦中でもモード選択に戻れます（確認あり）。
タイトルの「EDIT」からキャラの色（パーツごとに100色）を変えられます。
タイトルの「FRIENDS」から、あいことば4文字で友だちと直接つないで対戦できます（最大4人）。
へやをつくった人（ホスト）は、ステージと**せいげん時間（2:00 / なし）**を選べます。
「なし」にすると時間切れもサドンデスもなくなり、最後の1人になるまで続きます（時計は経過時間を数えます）。

## ログインとプロフィール

メールアドレスは不要です。**なまえ（ID）と あいことば**だけで登録できます
（メールアドレスを持っている人は、それをIDにしてもかまいません）。

- 一度ログインすれば、その端末では次から自動でログインされます
- 同じなまえとあいことばを入れれば、**スマホでもパソコンでも同じプロフィール**で遊べます
- プロフィールで変えられるもの：ゲーム中に表示される名前 / キャラの色（パーツごとに100色＋★6色）
- ストーリーの進みぐあいも保存されます（端末をまたいでも、進んでいるほうに合わせます）
- 戦績（あそんだ回数・優勝数・ラウンド勝ち）が自動で貯まります

データはVercelの非公開ストレージに保存され、あいことばはscryptでハッシュ化して保存しています
（元のあいことばはどこにも残りません）。ログイン状態はHMAC署名付きトークンで保持します。

## 中身について

`index.html` 1ファイルで完結しています。外部ライブラリなし、画像ファイルなし。
ドット絵はCanvasへの手描き、効果音とBGMはWeb Audio APIでその場で合成しています
（読み込むのはGoogle Fontsの2書体だけ。オフラインでも代替フォントで動きます）。

スーパーファミコン期の対戦アクションを思い出しながら作った
オリジナル実装で、既存作品のキャラクター・音楽・画像データは一切含みません。

## ローカルで動かす

`index.html` をブラウザにドラッグするだけで遊べます（ログイン機能以外はすべて動きます）。

かんたんなサーバー経由で見たいとき:

```
node serve.js
```

ログインAPI（`api/`）も含めて動かしたいとき:

```
npx vercel dev --listen 5177
```

→ どちらも http://localhost:5177
