# VORAZ ROBOT BATTLE

ボムを置いて壁を壊し、爆風で相手を吹き飛ばす、最大4人の対戦アクションです。
ブラウザで開くだけで遊べます。インストール不要・アカウント不要。

**遊ぶ → https://bomb-blast-arena.vercel.app/**

（予備URL: https://yanoken10.github.io/bomb-blast-arena/ ）

## あそびかた

- ボムを置いて逃げ、爆風で相手を倒す。最後の1人になったラウンドの勝ち。3ラウンド先取で優勝。
- ソフトブロック（茶色の箱）を壊すとアイテムが出ます。
- 残り30秒で**サドンデス**。外周から順にブロックが降ってきて、盤面がどんどん狭くなります。

### ステージ

| ステージ | イメージ |
| --- | --- |
| みどりの谷 | 山・川・森・岩 |
| まちなか | 都会・街・ビル |
| こうじ現場 | 工事・炭鉱・立入禁止 |

モードを選んだあとに選べます。「おまかせ」でランダムにもできます。

### アイテム

| アイテム | 効果 |
| --- | --- |
| FIRE | 爆風が1マス長くなる |
| BOMB | 同時に置ける数が増える |
| SPEED | 移動が速くなる |
| KICK | ボムを蹴って転がせる |
| PIERCE | 爆風がブロックを貫通する |
| REMOTE | 好きな瞬間に起爆できる |
| ロングボム | 爆風が一気に最大まで伸びる |
| ファイアトラップ | わざボタンで設置。前方に炎の壁が約5秒燃え続ける |
| ブタ | 乗ると壁を1マス跳び越えられる。1回やられるとブタだけ死んで自分は助かる |

### 操作

**スマホ・タブレット**：画面下の十字キーとボタン。十字キーは指を滑らせたまま方向を変えられます。

**キーボード**

| キー | 動作 |
| --- | --- |
| ← ↑ → ↓ | 1P 移動 |
| Space | 1P ボムを置く |
| Enter | 1P わざ（リモコン起爆・トラップ設置） |
| W A S D | 2P 移動 |
| F / G | 2P ボムを置く / わざ |
| P / Esc | ポーズ・再開 |

画面上部の「STOP」ボタンで、対戦中でもモード選択に戻れます（確認あり）。
タイトルの「EDIT」からキャラの色（100色）を変えられます。

## ログインとプロフィール

メールアドレスは不要です。**なまえ（ID）と あいことば**だけで登録できます
（メールアドレスを持っている人は、それをIDにしてもかまいません）。

- 一度ログインすれば、その端末では次から自動でログインされます
- 同じなまえとあいことばを入れれば、**スマホでもパソコンでも同じプロフィール**で遊べます
- プロフィールで変えられるもの：ゲーム中に表示される名前 / キャラの色（100色）
- 戦績（あそんだ回数・優勝数・ラウンド勝ち）が自動で貯まります

データはVercelの非公開ストレージに保存され、あいことばはscryptでハッシュ化して保存しています
（元のあいことばはどこにも残りません）。ログイン状態はHMAC署名付きトークンで保持します。

## 中身について

`index.html` 1ファイルで完結しています。外部ライブラリなし、画像ファイルなし。
ドット絵はCanvasへの手描き、効果音とBGMはWeb Audio APIでその場で合成しています
（読み込むのはGoogle Fontsの2書体だけ。オフラインでも代替フォントで動きます）。

スーパーファミコン期のボム設置型対戦アクションへのオマージュとして作った
オリジナル実装で、既存作品のキャラクター・音楽・画像データは一切含みません。

## ローカルで動かす

`index.html` をブラウザにドラッグするだけで遊べます（ログイン機能以外はすべて動きます）。

かんたんなサーバー経由で見たいとき:

```
node serve.js
```

ログインAPI（`api/`）も含めて動かしたいとき:

```
npx vercel dev --listen 5177
```

→ どちらも http://localhost:5177
